# Test fonts

Both are here so the suite covers the two outline formats without a network
fetch. Neither is used by the library at runtime.

`NotoNaskhArabic-Regular.ttf` — [Noto Naskh Arabic](https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic),
© The Noto Project Authors, [SIL Open Font License 1.1](https://openfontlicense.org/).
TrueType outlines, plus the composite glyphs and large glyph count that Arabic
brings with it.

`NewCM10-Regular-subset.otf` — [New Computer Modern](https://ctan.org/pkg/newcomputermodern),
© Antonis Tsolomitis, SIL Open Font License 1.1. Subset to Latin so the fixture
stays small. CFF outlines, which is the harder path.
